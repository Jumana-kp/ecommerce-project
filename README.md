# Full-Stack E-commerce Project

A full-stack e-commerce web application built with React, Django REST Framework, and PostgreSQL. The project includes a responsive shopping interface and a REST API for authentication, products, cart management, and orders.

## Project Structure

```text
ecommerce-project/
├── ecommerce-frontend/
├── ecommerce-backend/
├── README.md
└── .gitignore
```

## Technologies Used

**Frontend**
- React
- JavaScript
- Material UI (MUI)
- Redux Toolkit
- Axios
- React Router

**Backend**
- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication

## Features

- User registration and login
- Product listing and product details
- Product categories, variants, sizes, and colors
- Shopping cart management
- Checkout and order management
- Product reviews and ratings
- Responsive user interface
- REST API integration

## Setup

The frontend and backend are maintained in separate folders. Each has its own setup requirements.

- **Frontend:** Open `ecommerce-frontend` and follow its setup instructions.
- **Backend:** Open `ecommerce-backend` and follow its setup instructions.

Configure environment variables locally before running the application. Do not commit secret keys, passwords, or `.env` files.
