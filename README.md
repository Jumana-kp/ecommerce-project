# E-commerce Project

A full-stack e-commerce web application built using React, Django REST Framework, and PostgreSQL.

## Project Overview

This project provides an online shopping experience with product browsing, product details, user authentication, shopping cart management, checkout, order management, and product reviews.

## Technologies Used

**Frontend**
- React
- JavaScript
- Material UI
- Redux Toolkit
- Axios

**Backend**
- Python
- Django REST Framework
- PostgreSQL
- JWT Authentication

## Project Repositories

### Frontend
React-based user interface for browsing products, managing the shopping cart, and completing the shopping experience.

[View E-commerce Frontend Repository](https://github.com/Jumana-kp/ecommerce-frontend)

### Backend
Django REST API for authentication, product management, cart operations, checkout, orders, and reviews.

[View E-commerce Backend Repository](https://github.com/Jumana-kp/ecommerce-backend)

## Features

- User registration and login
- Product listing and product details
- Product categories and variants
- Shopping cart management
- Checkout and order management
- Product reviews and ratings
- Responsive user interface
- REST API integration
