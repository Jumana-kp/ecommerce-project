# Full-Stack E-commerce Application

A full-stack e-commerce web application developed using React and Django REST Framework, with PostgreSQL as the database. The application provides product browsing, user authentication, cart management, and checkout functionality.

## Project Overview

This project demonstrates the development of a full-stack e-commerce application with a React frontend and a Django REST API backend.

## Technologies Used

**Frontend**
- React
- Redux Toolkit
- Material UI
- Axios

**Backend**
- Python
- Django
- Django REST Framework
- JWT Authentication

**Database**
- PostgreSQL

## Key Features

- User registration and login
- Product listing and product details
- Product categories and filtering
- Shopping cart management
- Checkout functionality
- REST API integration
- Authentication and authorization
